A Python based tool to simulate a draft environment similar to Hearthstone's Arena format within the Genshin Impact Genius Invocations TCG game including support for deck themes, card rating balance, and exporting of complete deck codes

Download repo and use the .vbs tool to launch the drafting application 

Currently the program is also dependent on the following tools being installed- you will need the Python interpreter along with the following 3 dependencies installed. 

pandas==3.0.6
Pillow==12.3.0
Requests==2.34.2

Example command line statement to install - "pip install pandas"
